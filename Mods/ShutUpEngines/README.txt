📘 README – ShutUpEngines (v1.0)
Author : Alek

🎧 Description
ShutUpEngines est un mod client-side permettant de réduire fortement le volume de tous les sons du jeu via une simple touche (par défaut : K).
Idéal pour atténuer les bruits de moteurs, jouer plus confortablement ou couper les pics sonores. 
Aucune modification serveur requise.

⚙️ Fonctionnement
Activation / Désactivation :
- K → Active la réduction
- K → Désactive la réduction

Le mod :
- stocke ton volume original
- réduit le son à 1%
- restaure ensuite parfaitement le volume normal

Une icône HUD apparaît lorsque la réduction est active (ui_game_symbol_noise).

📑 Installation
1. Extraire le dossier “ShutUpEngines”
2. Le placer dans : 7 Days To Die/Mods/
3. Lancer le jeu sans EAC (Launch without EAC)

Test console : buff buffShutUpEngines

🔧 Compatibilité
- Compatible A21/A22/v1.0
- Fonctionne avec tous les mods client-side
- Non compatible EAC (normal pour mods C#)
